# AI Agent Platform

Reusable multi-tenant AI agent platform. ACOCAM is Tenant #1.

## Quick start

```bash
npm install
cp .env.example .env
npm run reindex
npm run dev
```

Open [examples/embed-demo.html](examples/embed-demo.html) or visit `http://localhost:8787/demo`.
