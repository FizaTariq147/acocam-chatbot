# WordPress adapter (Phase 3)

Thin plugin that loads the platform embed script and public config only.

## Install

1. Copy `adapters/wordpress/acocam-agent-embed/` into `wp-content/plugins/`.
2. Activate **ACOCAM Agent Embed**.
3. Settings → Agent Embed: set API base, embed script URL, tenant, agent, publishable key.
4. Enable the widget.

No conversation logic, knowledge, or ACOCAM APIs are implemented in WordPress.
